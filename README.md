# Fitness Bot Agentic AI Platform

Production-ready reference implementation for a modular fitness platform with:
- Node.js + Express backend
- PostgreSQL schema/migrations
- Agentic AI orchestration layer
- Next.js frontend

## Quick start
1. Copy env templates:
   - `cp backend/.env.example backend/.env`
   - `cp frontend/.env.local.example frontend/.env.local`
2. Run services with Docker Compose or start backend/frontend separately.
3. Open the app and go to **Setup** page to save your API keys and your side requirements.

See `docs/architecture.md` for the end-to-end design.
